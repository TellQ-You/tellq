TellQ v4.30 — 写真ページインジケーター更新不具合の修正

【今回の修正】
同じカラー内でメイン商品写真を前後に切り替えた際、ページインジケーターの表示が更新されない問題を修正しました。
写真の切り替え操作で現在の写真番号が変わるたびに、ドットと「現在枚数 / 総枚数」を即時更新します。

【変更範囲】
script.js の写真切り替え処理に、ページインジケーターの更新呼び出しを追加しました。
index.html は script.js のキャッシュバージョンのみ 4.30 に更新しています。
style.css と product-data.js は v4.29 から変更していません。
その他の機能・表示・商品データは変更していません。

【適用方法】
ZIP内のファイルを既存の TellQ_HP フォルダへ上書きしてください。
既存の image フォルダと .git フォルダは残してください。
